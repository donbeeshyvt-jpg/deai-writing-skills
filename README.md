# deai-writing-skills

四個繁體中文寫作技能：讓 AI 寫出來的字不再有 AI 味，還能帶上你自己的口吻。

[English](README.en.md) | **繁體中文**

---

你是不是也一眼就認得出 AI 寫的文章？開頭一句「在當今快速發展的時代」，中間塞滿「值得注意的是」，結尾再硬升華一次（讀到這裡應該已經想關掉了吧）。deai-writing-skills 就是專門處理這件事的四個繁中寫作技能。

它們分工很清楚：一個從零寫、一個檢查已經寫好的稿、一個把某人的口吻抓下來、一個寫或改要排上搜尋的文章。每個技能都是一份 `SKILL.md`（技能說明書，純文字檔），加上一個放細節表的 `references/` 資料夾。

不綁任何平台。每份 `SKILL.md` 裡都有一段可以整段貼的操作 prompt（給 AI 的開場指令），貼進任何聊天式 AI 都能用。這篇就來帶你看：四個技能各做什麼、怎麼裝、怎麼串，還有實測結果。

---

## 四個技能

| 技能 | 它幫你做什麼 | 什麼時候找它 |
|---|---|---|
| `deai-write` | 給它主題跟素材，直接寫出一篇繁中成稿。部落格、社群貼文、說明文件、email、銷售頁、口播稿都行。禁用句型在寫的當下就不寫，不用寫完再洗。 | 手上有題目和素材，要一篇從初稿就沒 AI 味的新內容。 |
| `deai-guard` | 檢查已經寫好的稿子，出一份有證據的報告（風險分數、五個維度、逐條命中），然後停下來問你要改哪幾條，你點頭才動手。 | 稿子寫好了，想先檢查，或檢查完再改。 |
| `deai-voice` | 把某個人怎麼說話、怎麼寫字反推回來，打包成三個檔的「角色卡」。第一個檔整段貼給任何 AI，它就照這個口吻寫。 | 想讓 AI 寫出某個特定的人的味道，通用的「自然文風」不夠用的時候。 |
| `deai-writing-seo` | 寫新文或改舊文，讓文章排得上搜尋、發得動社群。它先確認你真正想講什麼，關鍵字照權重擺位，改舊稿只動必要的地方，保住你原本的語氣。 | 文章要衝搜尋排名、要放關鍵字，或社群貼文觸及很差想調整。 |

四個技能都能單獨用，想串起來也可以（串法在後面）。

## 四條共用底線

每個技能都守這四條，沒得商量：

1. 不幫文字判身分。技能只會說「這幾處有 N 個 AI 味特徵」，絕不說「這一定是 AI 寫的」，也不會丟一個生成機率百分比給你。
2. 查不到就留白。不編事實、數字、第一手經驗，缺的地方標 `[待補]` 或 `[待查]`（寧可空著，也不要假的）。
3. 偵測會誤判，所以會降級。短文、技術文件、公文、學術摘要、非母語中文、SEO 制式文，都會放寬標準，不硬判 AI 味。
4. 保護片段不動。改寫時，數字、術語、引用、指令、專有名詞一個字都不碰，換的只有說法。

## 怎麼裝：三種方法

### 方法一：直接貼 prompt（任何 AI 都行）

完全不用安裝，最快：

1. 打開任一份 `SKILL.md`，找到「可直接貼的操作 prompt」那一段。
2. 整段複製，貼進 ChatGPT、Claude、Gemini，或你平常在用的聊天式 AI。
3. 接著把主題、稿子或樣本丟給它，它就照同一套步驟走。

小提醒：`deai-voice` 平常會產出三個檔，在不能建檔的聊天室裡，它會改成在對話裡分三段給你，自己存下來就好喔！

### 方法二：裝進 Claude Code（講到關鍵字就自己啟動）

Claude Code 會自動讀「技能資料夾」裡的技能。裝好之後，講到觸發詞（例如「幫我檢查 AI 味」）它就會自己啟動，也可以直接打 `/deai-guard` 這種斜線指令叫它出來。

第一步，把 repo（程式碼倉庫）下載到隨便一個地方：

```
git clone https://github.com/donbeeshyvt-jpg/deai-writing-skills.git
```

第二步，把裡面四個技能資料夾複製進技能資料夾。

macOS／Linux：

```
mkdir -p ~/.claude/skills && cp -r deai-writing-skills/deai-* ~/.claude/skills/
```

Windows（PowerShell）：

```
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse deai-writing-skills\deai-* "$HOME\.claude\skills\"
```

只想給某個專案用的話，改放進那個專案的 `.claude/skills/` 就好。

第三步，檢查一下，複製完應該長這樣：

```
~/.claude/skills/
├── deai-write/SKILL.md
├── deai-guard/SKILL.md
├── deai-voice/SKILL.md
└── deai-writing-seo/SKILL.md
```

⚠️ 重點要記住：不要把整個 repo 直接 clone 進技能資料夾！變成 `~/.claude/skills/deai-writing-skills/deai-write/SKILL.md` 這樣多包一層，Claude Code 一個技能都找不到（實測過，四個全部消失）。

新增的技能通常不用重開就會生效；沒出現的話，重開一次 Claude Code 就好。

### 方法三：裝進 Codex

Codex（OpenAI 的程式助理）也吃同一種技能格式。照 [Codex 官方文件](https://developers.openai.com/codex/skills)，個人技能資料夾是 `~/.agents/skills/`，一樣把四個技能資料夾複製進去。每個技能附的 `agents/openai.yaml`，是給 Codex 介面顯示用的名稱和說明（Codex 這邊只對過官方文件，還沒實機測過喔）。

## 四個技能怎麼用

### deai-write：從零寫一篇

講「幫我寫一篇貼文」「生成文章」「直接寫出沒有 AI 味的內容」這類話就會啟動。動筆前它會先問五件事：主題、素材（還有每份素材是你本人的、官方的，還是待查的）、場景、目標讀者，以及你希望讀者看完做什麼。它先給你一份施工圖（寫作計畫），你確認了才寫全文；交稿前，11 項檢查加 5 個維度的自評已經跑完。

### deai-guard：先檢查，你點頭才改

打「檢查 AI 味」「去 AI 味」「幫我看這篇像不像 AI 寫的」就會啟動。它會先問一句：只要報告，還是檢查完順便改？報告裡每一條命中都列出原句、問題、為什麼像 AI、建議改法，還有「可能誤判」。接著它會停下來，等你選要改哪幾條（沒收到你的選擇，一個字都不會動）。改完再給你改前改後的對照，外加一次殘留檢查。

### deai-voice：把口吻打包成角色卡

要抓某個人的口吻，說「提煉語氣」「蒸餾說話方式」「抓某人的寫作習慣」都行。它會先過授權關卡：只收你本人、你被授權代理，或具名公眾人物的公開內容。一個特徵要在三份以上的樣本裡重複出現，才算數。

最後你會拿到一個角色卡資料夾。第一個檔 `1-說話格式.md` 整段貼給任何 AI，它就照這個口吻寫；第二個檔 `2-資料庫.md` 是完整的口吻分析，每一條都附原文範例；第三個檔 `3-來源索引.md` 記錄樣本從哪來、什麼時候抓的，只給人看，不餵給 AI。

### deai-writing-seo：寫一篇排得上搜尋的文

文章想衝排名的時候，丟一句「SEO 優化」「改寫成 SEO 文章」「融入關鍵字」或「幫我下標題」給它。開工前它會先問任務型態（新寫、舊稿 SEO 化、社群轉換、局部微調）、核心關鍵字、受眾、平台跟目的。

改舊稿的話，它會先把「你這篇想講什麼、想達到什麼效果」的推測回報給你確認，猜錯就整組重來；數據、步驟、立場、口頭禪先鎖起來不准動。搜尋意圖直接看那個關鍵字的搜尋結果第一頁在排什麼（不靠猜），關鍵字照權重擺位，一頁只鎖一個核心意圖。演算法規則一律當參考方向，不當成事實寫。

## 四個技能怎麼串

它們設計成可以互相交棒：

```
deai-voice  →  deai-write        →  deai-guard
 抽口吻         填進風格輸入寫稿      獨立複審

deai-voice  →  deai-writing-seo  →  deai-guard
 抽口吻         寫要排名的文章        獨立複審
```

簡單來說，先用 `deai-voice` 把口吻做成角色卡，把第一個檔貼進 `deai-write` 的「風格輸入」欄；要排名的文章，就改交給 `deai-writing-seo`。寫完丟給 `deai-guard` 再看一次，它等於獨立的第二雙眼睛。

分開用也完全沒問題，串起來只是多一個選擇。

## 實測結果

2026 年 9 月，在 Claude Code 2.1.281 加 Opus 5.5、只裝這四個技能的環境下實測觸發：33 題真實請求，每題跑 2 次，一共 66 次。

- 該觸發的 25 題：50 次全部叫對技能。其中 4 題是兩個技能都說得通的混合題（例如「去 AI 味順便放關鍵字」「用我的口吻寫 SEO 文」），也都交給了比較專門的那一個。
- 8 題陷阱題（翻譯、只挑錯字、判斷圖片是不是 AI、技術 SEO 設定等）：16 次，0 次誤觸。
- 要注意的例外：短短幾行的「潤稿一下」，有時 AI 會覺得自己改就好，不叫 `deai-guard`（在裝了很多技能的環境比較常發生）。想走完整流程，直接打 `/deai-guard`。

（只在一台電腦、一個模型上測過，換模型或換版本，結果可能不一樣。）

## 限制與已知狀況

- 偵測不是證明。風險分數低，不代表一定是人寫的；分數高，也不代表一定是機器寫的。技能只是替特徵排優先順序。
- 以繁體中文為主。規則照繁中與中英混排調校，其他語言不在範圍內。
- 演算法規則多半是推測。`deai-writing-seo` 用到的社群與搜尋演算法規則沒有官方完整文件，技能一律當參考方向。
- 短文潤稿不一定會觸發 `deai-guard`（見上面的實測），要完整流程就打 `/deai-guard`。
- claude.ai 網頁版的技能上傳還沒實測過；想在網頁版用，先用方法一貼 prompt 最保險。

## 這份 README 怎麼寫出來的

先用 `deai-voice` 從 39 篇台灣的公開教學文、科普文，歸納出一張「網文聊天體」角色卡（文類口吻，不模仿任何特定作者），貼進 `deai-write` 的風格輸入寫成這篇，最後用 `deai-guard` 檢查過一輪。

所以如果你讀到一半覺得「欸，這很像 AI」，那就是技能還要再練（歡迎開 issue 來抓 XD）。裝好之後，挑一篇你最近寫的稿子丟給 `deai-guard` 試試看吧！
