# 五維度評分與降級校準

這份是 deai-guard 第二段算分用的細則。內容涵蓋五個維度的評分錨點、加權原則、中文特有校準、短文本規則、各文類降級處理，以及分數的性質聲明。照這份逐條打分，不要憑感覺給數字。

分數是排序工具，用來把命中的嚴重度排出先後，不是 AI 生成的機率。這一點在最後一節再講清楚。

## 一、五維度評分錨點

每個維度打 0 到 100，越高越像 AI。下面給每個維度的 0 分、50 分、100 分三個錨點，各配一個中文例子。實際打分時對照最接近的錨點，落在中間就取中間值。

### 空泛度（有沒有講具體的事）

| 分數 | 錨點 | 中文例子 |
|---|---|---|
| 0 | 每個主張都帶得出施事者、動作、可查的細節 | 「我把烤箱調到 210 度烤 12 分鐘，表面才上色。」 |
| 50 | 有具體也有空話，具體的部分撐不起整段 | 「這款相機的對焦很強大，在各種場景都能帶來優異表現，我拿它拍過幾次貓。」 |
| 100 | 整段都是抽象名詞和重要性宣告，抽掉形容詞就沒東西 | 「優質的內容策略能夠全方位賦能品牌成長，打造難以取代的核心競爭力。」 |

判斷訣竅：把形容詞和抽象名詞遮住，看剩下的骨架還能不能還原一件具體的事。還原不出來就往高分走。

### 來源感（主張有沒有出處）

| 分數 | 錨點 | 中文例子 |
|---|---|---|
| 0 | 有具名來源，或明講是自己的觀察與經驗 | 「衛福部 2023 年的統計是這個數字」「這是我自己顧店三年的體感，沒做過調查」 |
| 50 | 有揭露但模糊，讀者知道大概從哪來但查不到 | 「業界普遍認為」「相關研究指出過類似結論」 |
| 100 | 權威口吻，零來源，也不承認是自己講的 | 「研究顯示」「專家一致認為」「數據早已證明」後面接一個沒出處的斷言 |

注意區分：作者本人就是資料的來源時（例如店主講自己店裡的事），不算來源模糊，往 0 分走。

### 模板度（結構是不是公式）

| 分數 | 錨點 | 中文例子 |
|---|---|---|
| 0 | 開頭直接進入內容，結尾停在具體事實或未解的問題 | 開篇第一句就是「昨天那批貨少了三箱」，結尾停在「箱號對不上，還在查」 |
| 50 | 有一兩處套路（例如收尾升華），但主體是實寫 | 全文都在講操作細節，最後補一句「這也算是一種修行吧」 |
| 100 | 宏大開場加二元對比加金句收尾，三件套齊全 | 「在這個資訊爆炸的時代」開場，中段「這不只是技術，更是態度」，結尾「未來，已來」 |

### 節奏勻稱度（句長段長是不是機械）

| 分數 | 錨點 | 中文例子 |
|---|---|---|
| 0 | 長短句交錯，段落有長有短，該停就停 | 「他沒回。整整三天。我後來才知道他手機掉了。」 |
| 50 | 大致有起伏，但某幾段明顯規整，或轉折詞用得太準時 | 每段都是「首先…其次…最後」，句子長度卻還有些變化 |
| 100 | 句長幾乎等長，段落等寬，每段都掛粗體，轉折詞頻率固定 | 連續五段都是「兩個逗號一個句號」的三拍結構，每段開頭都加粗一個小標 |

這個維度權重最低，理由見第二節。中文的句長本來就比英文波動大，打分時放寬，見第三節校準。

### 聲音缺失度（有沒有真人立場）

| 分數 | 錨點 | 中文例子 |
|---|---|---|
| 0 | 有第一人稱、有取捨、有講出自己的限制或猶豫 | 「我試過另一種做法，失敗了，所以現在只敢用這個，但我不確定換個場景還行不行。」 |
| 50 | 有立場但很淡，像是安全的通用意見 | 「我覺得這個方法還不錯，適合大部分人。」 |
| 100 | 全篇沒有人稱、沒有取捨、沒有限制，像誰都能講的正確話 | 「我們應當重視這個議題，並採取積極有效的措施加以應對。」 |

## 二、加權原則與理由

總分是五維度的加權平均。權重高低照下面的排序，不給精確的百分比係數，因為目前沒有實測資料能支撐某個確切數字，硬給只會製造假精確。

從高到低：

1. 空泛度（最高）。空泛是 AI 味最核心的特徵，也最難靠改標點蒙混。內容空的文章，換再多句式還是空。
2. 來源感（次高）。無來源的權威聲稱是誤導風險最高的一類，也是人類作者最容易被冤枉又最該被提醒的一項，所以給高權重但配合誤判欄。
3. 模板度（中）。結構套路很明顯，但某些文類（SEO、公文）本來就套結構，所以權重居中，靠文類降級調整。
4. 聲音缺失度（中）。缺個人立場是強信號，但學術、公文、技術文件本來就該去個人化，容易誤判，權重居中。
5. 節奏勻稱度（最低）。句長段長的規整最容易誤判，中文尤其（見第三節）。它適合當旁證，不適合當主判，所以權重最低。

操作原則：算總分時，讓空泛度和來源感這兩項主導排序。當某篇的節奏勻稱度很高但空泛度和來源感都低，總分應該偏低，不要被節奏一項拉高。

## 三、中文特有校準

英文那套檢測參數不能直接套到中文，下面三項要特別調。

### 句長波動比英文大

中文一個句子可以很短（「他走了。」），也可以靠逗號串很長，這是中文的正常節奏，不是刻意變化。不要機械套用英文寫作檢測常用的「最大句長比最小句長」門檻。中文出現長短懸殊是常態，不能因為某段句長方差大就判它「刻意營造節奏」，也不能因為方差小就直接判 AI。節奏勻稱度這一維度在中文文本要看得寬鬆些。

### 引述常省年份出處

中文寫作，尤其是散文、評論、口語轉錄，引述時常省略年份和完整出處，直接說「有研究說」「古人講過」。這是中文書面語的習慣，不一定是 AI 在假造權威。判斷要看兩點：一是上下文有沒有補足夠的細節讓人知道大概指什麼，二是作者的身分適不適合這樣講（一個講故事的人省出處，比一篇宣稱數據的行銷文省出處，可信得多）。省出處本身先標 [待查]，不要直接當 [無來源] 扣重分。

### 成語隱喻要分文化表達與 AI 拔高

成語、俗諺、隱喻在中文裡是自然的表達工具，用了不等於 AI 味。要區分兩種用法：

- 文化表達（不扣分）：成語用得貼、有具體所指，替代了一句更囉唆的白話。例：「這批貨拖了半年還沒到，真的是遠水救不了近火。」成語服務於具體的事。
- AI 拔高（扣分）：成語或華麗隱喻堆疊，用來替代內容，把空話講得像有份量。例：「唯有厚積薄發，方能行穩致遠，於時代浪潮中破浪前行。」三個四字詞連用，底下沒有任何具體的事。

判準還是回到空泛度：隱喻底下有沒有具體所指。有，是文化表達；沒有，是拔高。

## 四、短文本評分規則

短文本信號不足，強行跑五維度會製造假分數。照長度分三檔，這一段和 SKILL 第一段的降級規則對齊。

- 500 字以上：完整五維度評分。
- 300 到 500 字：不做五維度打分，只出風險等級加最嚴重的 3 條命中加修正方向。命中超過 3 條也只留最嚴重的 3 條，其餘不列，避免在資訊不足的短文上堆一堆低信度判斷。
- 300 字以下：只看邏輯有沒有矛盾、用詞有沒有明顯拼接痕跡。不打分、不跑維度，報告直接寫「短文本信號不足，只做輕量判斷」。

短文本不出五維度數字，是為了不讓使用者拿一個沒有統計基礎的分數當真。


## 五、各文類降級處理

不同文類的規則化程度不同，硬用同一把尺會冤枉本來就該規整的文章。下面說明每一類「降什麼、往哪個方向降」，用質性描述，不給精確的降級係數百分比（那種係數目前沒有實測依據，捏出來只是假裝嚴謹）。

| 文類 | 降什麼 | 方向與理由 |
|---|---|---|
| SEO 制式文 | 模板度、節奏勻稱度大幅調低 | 標題重複關鍵字、H 標籤結構、FAQ 排列是 SEO 需求，不是 AI 味。重點放空泛度和來源感。 |
| 技術文件 | 鎖術語，模板度、聲音缺失度大幅調低 | 術語一律不進扣分，去個人化和步驟化是文類需求。只看開場結尾有沒有機械套話。 |
| 學術摘要 | 聲音缺失度、模板度大幅調低，背景鋪陳不扣分 | 被動語態、背景鋪陳、去第一人稱是學術寫作規範，不是 AI 拔高。空泛度仍看，因為摘要也可能真的空。 |
| 公文、email | 幾乎全維度調低，只留明顯機械開場 | 稱謂、制式結尾、法規語是格式要求。只清最明顯的暖場套話，其餘不判。 |
| 非母語中文 | 翻譯腔、詞彙層權重大幅調低 | 「透過…來實現」這類可能是翻譯痕跡或非母語表達，不是 AI。重點移到內容密度和邏輯，先問這是不是翻譯或改寫過的。 |
| 文案、landing | 保留 SEO 結構，只看段落節奏 | CTA、賣點重複是轉化需求。不動結構，只評段落層的空泛和節奏。 |

降級的操作方式：把該調低的維度分數往下壓，或在總分加權時給它更低的比重，並在報告的「可能誤判」欄寫清楚為什麼降。降級不是不看，是把它從主判降成旁證。

## 六、分數性質與準確率聲明

這一節必須進報告，不能省。

分數是排序工具，不是判決。五維度的總分只用來把命中的嚴重度排出先後，方便使用者決定先看哪幾條。它不代表這篇文章由 AI 生成的機率，報告裡不准把分數講成「AI 生成機率」或「像 AI 的百分比」。

偵測器和規則的準確率有限，會誤判。學界對 AI 文本偵測器的評估普遍指出其準確率偏低，對非母語寫作和規則化文類尤其容易誤判。因為找不到一個可靠通用的準確率數字，這裡不寫具體百分比，只說明：任何單一分數或規則命中都可能是誤判，不能當唯一判決。

所以有兩條硬規定：

1. 報告永遠附這句或等義的話：「分數用於排序命中的嚴重度，不代表 AI 生成機率。」
2. 每條命中都要有「可能誤判」欄，說明這條在什麼情況下其實正常。沒有這一欄，這個技能就退化成一個普通偵測器。

最終判斷權在使用者。分數幫他排序，誤判欄提醒他風險，改不改由他決定。

## Codex 版補充（保留 ai-tone-audit 的獨有維度與分級）

這一段補進來源為 Codex 版 ai-tone-audit 的獨有內容，base 前面各節沒有涵蓋的才列。base 是地板，這裡只增不改。用法：base 的五維度（空泛度／來源感／模板度／節奏勻稱度／聲音缺失度，0 到 100）仍是主判；下面這套是另一組命名與另一種分級刻度，當作對照與快速定位工具，不取代 base。

### 另一套五維度命名與定義（1 到 5 分，分數越高風險越高）

這組維度名稱和 base 的五維度不同，切點也不同，可在快速掃描時當作另一個角度的檢查表。每項 1 到 5 分。

| 維度 | 看什麼 |
|---|---|
| 直接性 | 是否一直暖場、宣告、鋪陳，不進重點 |
| 具體性 | 是否抽象拔高，缺少人物、動作、時間、條件 |
| 節奏 | 是否句長、段落、轉折都太平均 |
| 來源感 | 是否用模糊權威、無來源共識、假客觀 |
| 個人聲音 | 是否沒有立場、限制、取捨、真實觀察 |

對應關係（供交叉參照，非強制換算）：直接性對應 base 的模板度偏開場那一面，具體性對應空泛度，節奏對應節奏勻稱度，來源感與 base 同名，個人聲音對應聲音缺失度。兩套並存時以 base 的 0 到 100 版為報告主分，這套 1 到 5 版只當旁註。

### AI 味風險分級文字表（0 到 100 的整段判讀）

base 有 0 到 100 的總分，但沒有把分數段落對應到文字判讀。這張表補上文字分級，用來把總分翻成一句人看得懂的結論與下一步。用 `AI 味風險`，不要用 `AI 機率`。

| 分數 | 判斷 |
|---:|---|
| 0-20 | 很低，主要是正常制式表達 |
| 21-40 | 有零星模板句，局部修即可 |
| 41-60 | 中度 AI 味，需段落級整理 |
| 61-80 | 明顯 AI 味，需重寫結構與語氣 |
| 81-100 | 高度模板化，需回到素材重建 |

### 「刪掉開頭前 1 到 2 句後意思不變」判斷法

這是一個快速的開場檢驗法，base 的宏大開場判斷問句是「刪掉整段暖場有沒有損失」，這一條更聚焦到句層：把文章開頭的前 1 到 2 句刪掉，如果整篇的意思沒有任何改變，這 1 到 2 句通常就是純暖場的 AI 味，命中。反之若刪掉後讀者會漏掉必要前提（例如學術摘要的研究背景），不算。這條可以在逐段掃描開場時直接套用，比整段判斷更快定位。

### 具體例句補充（base 詞表未列到的）

base 的 `references/ai-tone-patterns.md` 已收「賦能／打造／閉環／生態」等公關腔詞。下面這些是 Codex 版另外點名、base 詞表尚未逐字列出的高風險句型與詞，補進來當掃描對照樣本。單點仍降級、聚集才算，判定回到 base 的判斷問句。

- 抽象拔高類：`象徵著`、`標誌著`、`為…奠定基礎`、`帶來全新的可能性`。判斷：要求它回答「誰做了什麼、改變了什麼、證據在哪裡」，答不出就是風險。
- 公關腔類：`降本增效`、`生態矩陣`（與 base 已有的 `賦能`、`打造閉環` 同屬一類，這兩個 base 未逐字列，補上）。
- 空泛鼓勵類：`一起迎接更好的未來`、`共創美好明天`。判斷：這句刪掉讀者會不會漏掉任何事實或行動指示，不會漏掉就是純填充，命中。
