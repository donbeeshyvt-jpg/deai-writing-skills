# 多方位深度提煉說話方式

把一個人的說話與寫作方式，蒸餾成一份結構化、可重用的東西。頭號產物是一個「角色卡資料夾」（`角色卡deai-voice-{角色名稱}`，資料夾本身就是資料包）：內固定三檔，分別是 `1-說話格式.md`（可直接貼給任何 AI 的生成規則＋語境錨點＋開場示範＋尾部重錨卡，乾淨無溯源）、`2-資料庫.md`（口吻的多角度詳細解析＋原文範例庫，每條特徵連回來源索引）、`3-來源索引.md`（樣本來源、網址、搜尋時間、維度覆蓋表、驗證與擴充日誌，永不進 prompt）。人讀用的完整 profile 等同檔案 2＋檔案 3 的合體。

這不是「猜一個人是誰」，是「描述這個人怎麼組織語言、怎麼推理、語氣停在哪裡」。描述的每一條都要能指回具體樣本，指不回去的就不寫。

## 這技能在做什麼，不做什麼

做：抽取語言表層特徵（詞彙、標點、句長、段落、開場、收尾），抽取深層特徵（推理順序、取捨方式、承認不確定的方式、對讀者的距離、情緒與幽默的邊界、常用類比與世界觀傾向），標註每條特徵的信心等級，最後打包成可貼給 AI 的設定。

不做：不從三五句話推出一個人的完整人格；不虛構對象的觀點、經歷、政治立場、私人資訊；不冒用身分去發布假內容；不把「這個人一定是這樣想」當結論寫。抓不到就標，不補。

## 核心原則

1. 樣本說了算。profile 裡每一條都要能對應到樣本裡的實際文字。抽象講「他很有個性」沒用，要講「他句子平均 12 到 18 字，段落 2 到 3 行，愛用『欸』『其實吧』開頭，但『其實』一篇不超過 2 次」。

2. 跨樣本重複才算核心。單一樣本出現一次的習慣可能是當天狀態，不是穩定特徵。同一個模式要在 3 份以上獨立樣本裡重複，才能列進 profile 的核心層。只出現 1 到 2 次的放「觀察到但不確定」區。

3. 深層是重點，但表層裡有高價值訊號別低估。詞彙和標點誰都數得出來，AI 只靠這些模仿容易像皮不像骨。真正讓一個人是這個人的，是他先講結論還是先鋪背景、遇到不確定怎麼說、對讀者是拉近還是保持距離、笑點落在哪裡，這層要花力氣。但表層不是都一樣廉價：虛詞與功能詞、標點、句長節奏是最穩定、最抗改寫、最不受主題影響的一類指紋，要獨立抽、優先抽。抽它們是替深層鋪路，不是取代深層。

4. 只用授權或公開內容。使用者自己提供的樣本，預設可用。要主動上網補樣本，必須先過授權閘門（第 1 關）。查不到就標 `[樣本不足]`，不要為了湊滿 profile 去編。

5. 誠實邊界。不虛構對象的世界觀、立場、生平。可以寫「在這幾篇樣本裡，他傾向用工程比喻」，不能寫「他是個理性主義者」。前者是觀察，後者是替對方定性。經 AI 改寫過的樣本要降權（第 2 關）。

## 嚴格執行流程

照順序走，每一關做完再進下一關。閘門不過就停下問使用者。

### 第 0 關：對象與用途確認

先問清楚，別急著分析：

- 對象是誰？是使用者自己、某個具名公眾人物、還是匿名的一批文字？
- 要拿 profile 做什麼？（自己寫東西時對照、餵給 AI 代寫、團隊統一文風、單純研究）
- 樣本從哪來？使用者會貼，還是要我上網找？

用途會影響深度。餵給 AI 代寫要完整三檔資料包（含可直接貼的說話格式）；單純研究可以只出檔案 2＋檔案 3（分析與溯源），並註明未編譯說話格式。

### 第 1 關：授權與倫理閘門

這關決定樣本怎麼來，過不了就不往下走。細則與灰色地帶案例在 `references/authorization-ethics.md`。

先判斷屬於哪種情況：

| 情況 | 樣本來源 | 是否放行 |
|---|---|---|
| 對象是使用者本人 | 使用者提供 | 放行 |
| 對象授權使用者代理（有委託關係） | 使用者提供 | 放行 |
| 具名公眾人物的公開發表內容（文章、書、公開演講、公開貼文） | 使用者提供 或 web 搜尋 | 過倫理檢查後放行 |
| 私人對話、私訊、非公開文件 | 任何來源 | 不放行，除非對象明確授權 |
| 意圖冒充對方發布、詐騙、抹黑、假冒背書 | 任何來源 | 一律不放行 |

要主動 web 搜尋補樣本前，逐條確認：

1. 對象是具名公眾人物，不是私人。
2. 要抓的是公開發表過的內容，不是私領域。
3. 用途不是冒名、詐騙、騷擾、政治操作。
4. 使用者確認願意為用途負責。

四條有一條過不了，就停下來，只用使用者手上已有的授權樣本。任何一步涉及冒充真人發言，直接拒絕並說明原因。

**沒有搜尋能力時的降級路徑：** 如果環境沒有 web 搜尋工具，或搜尋被限制，就不主動找樣本，改成只用使用者提供的樣本，並在 profile 開頭註明「樣本僅來自使用者提供，未做公開內容補樣，信心等級據此下調」。不要因為搜不到就用記憶裡對這個人的印象填補，那等於虛構。

### 第 2 關：收集與分級樣本

目標湊到 5 份以上獨立樣本，每份最好 300 字以上。長度不夠、數量不夠就照實說，profile 的信心等級會整體下降。

每份樣本標四件事：

- 來源（使用者提供 / 某網址 / 某本書）
- 類型（長文 / 貼文 / 訪談口語 / 郵件 / 技術文件）
- 時間（發表或書寫的大概時間。樣本跨多年時，時間漂移要處理，見第 4 關）
- 是否經 AI 改寫或代筆

AI 改寫過的樣本降權：這類樣本本身就帶 AI 味，拿來當「這個人的自然口吻」會污染 profile。標記後只當輔助，不當核心依據。判斷不了是否 AI 改過，就問使用者。判斷「是否被 AI 改過」本身也是一種偵測，會誤判，所以用它降權、不用它下定論；訊號可參考 `deai-guard` 的 AI 味清單。

好樣本與壞樣本要分開收。如果使用者能提供「這篇很像他」與「這篇不像他、別學」的對照，抽取會準很多。主動請使用者標出不要模仿的樣本。

同一個人在不同場景講話不一樣（寫論文相對於發限動）。樣本類型混雜時，profile 要分場景寫，別把技術文件的嚴謹算進他日常的隨性。

樣本來源是語音（訪談、播客、語音訊息、直播）時，先套 `references/spoken-samples.md` 的逐字處理，別在抽取前把逐字稿清成通順文字，否則停頓、改口、未完成句這些最認人的訊號會流失。

選用步驟：對象是使用者本人或授權代理時，可在抽取前做一次引導式偏好訪談，補問樣本問不出的隱性偏好（刻意迴避哪些寫法、場景怎麼切換）。訪談答案標「本人自陳」，補強信心但不自動當 high。具名公眾人物不得代答訪談，界線見 `references/authorization-ethics.md` §七。

### 第 3 關：多維抽取

分兩層抽。表層先掃，深層細讀。每個維度都記下「證據句」和「出現次數／樣本數」。逐維操作說明與中文實例對照在 `references/extraction-dimensions.md`，口語樣本的逐字處理與口語專有維度另見 `references/spoken-samples.md`。

表層維度（可量化，直接數）：

| 維度 | 抽什麼 |
|---|---|
| 詞彙 | 高頻實詞（需過主題過濾）、虛詞與功能詞（優先指紋）、口頭禪與慣用過場句、成語密度、術語密度、第一人稱頻率、自嘲詞 |
| 標點 | 愛用哪些標點、驚嘆號問號密度、有沒有慣用省略號、括號補充的頻率、（繁中場景）全形習慣 |
| 句長 | 平均句長、句長變化幅度、有沒有慣用的極短句作節奏 |
| 段落 | 平均段長、段落是否等長、換行習慣、有沒有單句成段 |
| 開場 | 文章或段落怎麼起頭：直接破題、拋問句、講場景、還是先給結論 |
| 收尾 | 怎麼收：回扣開頭、停在事實、拋開放問題、還是慣性升華（若有升華，照實記，不美化） |
| 社群與夾雜 | emoji 與顏文字、標點連用、空格斷行、中英夾雜與數字寫法（有社群或即時通訊樣本時抽） |

深層維度（要細讀，重點在這）：

| 維度 | 抽什麼 | 怎麼記 |
|---|---|---|
| 推理順序 | 先結論後理由，還是先鋪陳後結論？歸納還是演繹傾向 | 引 2 到 3 段展示他的推理骨架 |
| 連接鏈 | 慣用把哪些小詞串成固定接法（其實…但…、先…再…最後…） | 記 2 到 3 個固定框架，這層抗改寫 |
| 謀篇結構 | 整段整篇怎麼鋪展、段落功能序列、承轉怎麼接 | 引 1 到 2 篇標出段落功能序列，長文最露餡 |
| 取捨方式 | 面對複雜問題怎麼取捨、怎麼標重點、什麼會被他省略 | 記他「略過什麼」和「放大什麼」 |
| 承認不確定 | 用什麼句式承認自己不知道、會不會 hedge、hedge 的密度 | 記原句，如「我不確定」「應該吧」「還沒搞懂」 |
| 對讀者距離 | 拉近（你我對話）還是保持距離（旁觀陳述）？教學還是平視 | 記人稱用法與招呼方式 |
| 情緒邊界 | 情緒表達的上限與下限，會不會激動，激動時怎麼寫 | 記情緒峰值的句子 |
| 幽默邊界 | 有沒有幽默、哪種（自嘲／冷面／誇張／諧音）、笑點落在哪 | 引一個代表性笑點，拆解它為什麼好笑 |
| 類比傾向 | 慣用哪個領域的比喻（工程、運動、料理、生活） | 列 2 到 3 個實際類比 |
| 佐證習慣 | 論證靠什麼撐（親身經歷、數據、引用權威、假設、類比） | 記最常倚重的佐證型態，與類比傾向區隔 |
| 世界觀傾向 | 只記「在樣本裡反覆出現的看事情角度」，不上升為人格定性 | 用「在這些樣本中傾向……」句式，禁止「他是個……的人」；只供理解，不進短 prompt 與生成層 |

深層維度最容易越界。守住一條線：描述他怎麼說，不替他總結他是誰。「在樣本裡他常先認錯再解釋」可以，「他是個謙虛的人」不行。

錯字、口誤、病句預設不列為特徵。這些多半是當下手誤，不是穩定風格。除非使用者明確指定「這個錯法就是他的味道」，才收，且標明是刻意保留。

### 第 4 關：穩定性判準與信心分級

抽完後過濾。每條特徵標信心等級（細則見 `references/confidence-and-stability.md`）：

- high：在 3 份以上獨立樣本重複出現，模式清楚。列入 profile 核心層。
- medium：在 2 份樣本出現，或 3 份裡有 1 份明顯不符。列入，但註明「較不穩定」。
- low：只在 1 份樣本出現，或樣本本身可能被 AI 改過。放「觀察到但存疑」區，不進核心。

樣本總數少於 3 份時，整份 profile 最高只能標到 medium，並在開頭寫明「樣本量不足，此 profile 為初步觀察」。

樣本時間跨度大時，標出來並以近期樣本為主，或分期記，別把對象早就淘汰的舊習慣當現在的穩定特徵（時間漂移，細則見 `references/confidence-and-stability.md` §七）。

樣本 5 份以上時，抽 profile 前先留 2 到 3 成樣本不看，建完再拿留樣檢查 high 特徵，只在建檔那批成立、留樣裡消失的特徵要降級（留樣驗證，防過擬合，細則見 `references/confidence-and-stability.md` §五）。樣本不足以留樣就誠實跳過並註明。

### 第 5 關：輸出三檔資料包（角色卡資料夾）

頭號出口是一個資料夾，資料夾本身就是資料包：名為 `角色卡deai-voice-{角色名稱}`，內固定三個檔案，自足、不依賴資料夾外的任何說明檔。格式與完整骨架見 `references/voice-pack-format.md`。資料流單向 3→2→1（樣本入索引 → 分析入資料庫 → 說話格式由資料庫編譯出來），日後擴充照這條流走：

- `1-說話格式.md`（可直接貼給任何 AI，乾淨無溯源）：恆常核心（規則與原句示範成對；六塊：語言表層、推理語氣、頻率上限（口癖帶觸發條件）、場景差分、反例對比三級（絕不用／少用／防群聚）、內建對齊 `deai-write` 的去 AI 味守則）＋語境錨點（3 到 6 組、各覆蓋不同語境、標可修剪）＋開場示範＋尾部重錨卡（對抗長對話漂移）＋邊界與揭露。恆常核心 500 到 2000 字。
- `2-資料庫.md`（詳實的多角度解析，唯一的完整分析）：口吻手冊表層與深層逐維（每條「怎麼下筆＋示範字句＋解析＋[信心]＋（樣本 X）」；同一功能多招列成招式庫）＋標誌模板庫（帶空格句型骨架）＋節奏與量化錨全表（實際數值，驗收基準）＋場景旋鈕詳版＋禁用清單三級＋聲音刻度卡＋原文錨點庫（分組附解析）＋條目化補充（特定話題才出現的用語）＋僅供理解區（世界觀傾向，不進檔案 1）。
- `3-來源索引.md`（溯源與擴充日誌，永不進 prompt）：取樣範圍＋樣本索引表（每筆含來源、網址、發表時間、搜尋時間、完整度、被哪些特徵引用）＋維度覆蓋表＋驗證紀錄（含遮名測試）＋版本與擴充日誌＋擴充指南＋授權提醒。

環境不能建立檔案時（例如整段 prompt 貼在網頁版聊天室），改成在對話裡依序輸出三個區塊，每塊第一行標檔名（`1-說話格式.md`／`2-資料庫.md`／`3-來源索引.md`），讓使用者自己存成三個檔；內容、順序與資料流都不變。

防收斂鐵則：打包前逐維過 `references/voice-pack-format.md` 第七節的「維度覆蓋檢核表」（表層 12 維＋深層 11 維＋口語 6 維），每一維都要有去處並記進檔案 3 的維度覆蓋表。抽取層抽到幾維，輸出層就要交代幾維；沒交代的維度等於靜默丟失，這是卡片變薄的頭號原因。

為什麼這樣分：範例勝過形容詞有實證（純描述風格匹配率不到 7%，few-shot 高 23.5 倍），所以檔案 1 用「規則＋原句」成對；溯源對寫作是雜訊但是本技能的誠實命脈，所以住檔案 3、不刪；檔案 2 是唯一的完整分析，特徵編號在資料庫層是連到索引的功能連結，不再分「卡片版／審閱檔版」寫兩遍。卡片是「詳實但只談口吻」，不是「精簡」：排除依相關性不是長度，口吻細節要寫足（那才是套卡要吸收的），砍的只有跟口吻無關的溯源。

人讀用的完整 profile 不廢除，等同檔案 2＋檔案 3 的合體。profile 模板、短 prompt 多場景變體、評分表都在 `references/output-templates.md`。先把分析審過、說話格式編譯到位，再出三檔。

### 第 6 關：測試改寫與驗證

profile 不能只是好看，要能用。做一次驗證：

0. 個體化前置：先寫一段完全不套 profile 的中性版（同主題、預設口吻）。跟套 profile 的版本並排，兩版差不多代表抓到的多是通用語氣，退回重抽（細則見 `references/confidence-and-stability.md` §六）。
1. 挑一個對象沒寫過的主題（不能是樣本原題，會分不出是模仿還是抄）。
2. 拿生成 prompt，照它寫一段 150 到 250 字。
3. 把這段跟真實樣本並排，逐條對照核心特徵有沒有中；同時查三件事：有沒有把某特徵放大到失真（反漫畫化，匹配樣本頻率而非最大化）、換題後有沒有抄原內容（內容外洩）、本身讀不讀得通（內容連貫度）。評分表在 `references/output-templates.md` §四。
4. 貼合度與內容連貫度雙軸，任一軸太低就回頭修 profile 或生成 prompt，再測一次。
5. 樣本 5 份以上時做留樣與盲測（判官要不知道答案，客觀工具優先，細則見 `references/confidence-and-stability.md` §五）。
6. 把這段測試改寫附在 profile 後面，讓使用者自己判斷像不像。

驗證同時也是誠實檢查：如果照 profile 寫出來一點都不像，代表 profile 抓錯了或樣本不夠，照實講，別硬說像。

## 人讀總覽模板（選用）

頭號產出仍是第 5 關的三檔資料包。只有使用者另外要一份人讀用的總覽時才用這份模板，它等同檔案 2＋檔案 3 的合體視圖，不取代三檔資料包。

    # Voice Profile：[對象名稱或代號]

    ## 基本資訊
    - 樣本數：X 份　樣本類型：……
    - 授權來源：……（含是否做過公開內容補樣）
    - 整體信心：high / medium / low
    - 限制聲明：本 profile 只描述樣本中的語言與推理模式，不代表對象的完整人格、立場或生平。

    ## 表層特徵
    ### 詞彙
    - [high] ……（證據：樣本 2、樣本 4、樣本 5）
    ### 標點
    - ……
    ### 句長與段落
    - ……
    ### 開場與收尾
    - ……

    ## 深層特徵
    ### 推理順序
    - [high] 先給結論，再補 1 到 2 個具體理由，很少長鋪陳（證據：樣本 1、3、5）
    ### 取捨方式
    - ……
    ### 承認不確定
    - ……
    ### 對讀者距離
    - ……
    ### 情緒與幽默邊界
    - ……
    ### 類比與世界觀傾向

    ## 觀察到但存疑（不進核心）
    - [low] ……

    照 profile 寫出的段落：……
    對照結果：核心特徵命中 X／Y

## 可直接貼給其他 AI 的短 prompt（模板）

短 prompt 是 profile 的壓縮版，只留 high 信心的核心特徵，控制在能一眼讀完的長度。檔案 1「說話格式」的恆常核心是它的詳細版（帶完整規則、原句示範、頻率上限、場景差分、反例對比、去 AI 味守則），這裡的短 prompt 是壓縮審閱版，打包格式見 `references/voice-pack-format.md`。

    你現在要模仿 [代號] 的說話方式寫作。規則如下：

    語言表層：
    - 句子平均 X 到 Y 字，長短交錯，[有／沒有]極短句作節奏。
    - 段落 X 到 Y 行，[等長／非等長]。
    - 慣用開頭：……　慣用收尾：……
    - 標點習慣：……（繁中場景全形標點，禁破折號）
    - 口頭禪／慣用詞：……（但每個詞一篇別超過 N 次）

    推理與語氣：
    - 推理順序：先……再……
    - 承認不確定時說：……
    - 對讀者：[拉近／平視／保持距離]
    - 幽默：[有／無]，型態是……
    - 常用類比：……

    邊界：
    - 不要虛構 [代號] 的觀點、經歷、立場。沒有依據的判斷就別寫。
    - 不確定的地方照 [代號] 的習慣承認，別硬裝懂。
    - 換新主題時不得替 [代號] 斷言他沒表過的事實或立場（非覆蓋聲明）。
    - 世界觀傾向只供理解，不寫進這段生成指令。用仿寫對外時標「AI 仿寫、非本人」。

## 可直接貼的逐步操作 prompt

要把整個流程交給另一個 AI 或人照做，貼這段：

```
你要幫我把某個人的說話方式，蒸餾成一份可重用的 voice profile。嚴格照以下步驟，不要跳步。

第 0 步：先問我三件事，對象是誰、profile 要拿來做什麼、樣本我會貼還是要你上網找。
第 1 步：過授權閘門。只有「我本人／我被授權代理／具名公眾人物的公開內容」才可用；
　私人對話、要冒名詐騙抹黑的，一律拒絕。要上網找樣本前，先確認對象是公眾人物、內容是公開的、用途正當。
　如果你沒有搜尋能力，就只用我貼的樣本，並在 profile 註明沒做公開補樣、信心下調。
第 2 步：收樣本，目標 5 份以上、每份 300 字以上。每份標來源、類型、是否被 AI 改過（被改過的降權）。
　也請我提供「不像他、別學」的壞樣本對照。
第 3 步：分兩層抽。表層數詞彙（含虛詞與功能詞這類優先指紋）、標點、句長、段落、開場、收尾；
　深層細讀推理順序、連接鏈、謀篇結構、取捨、承認不確定、對讀者距離、情緒與幽默、佐證習慣、常用類比、世界觀傾向。
　每條都要附證據句和出現的樣本數。只描述他怎麼說，不替他定性（可寫「常先認錯再解釋」，不可寫「他很謙虛」）。
　錯字口誤不算特徵，除非我說那就是他的味道。
第 4 步：跨 3 份以上樣本重複的才進核心（high）；2 份的標 medium；只 1 份或疑似 AI 改過的放存疑區（low）。
　樣本少於 3 份，整份最高只能 medium，並在開頭聲明樣本不足。
第 5 步：輸出一個資料夾「角色卡deai-voice-{角色名稱}」，內固定三檔（不能建立檔案時，就在對話裡依序輸出三個區塊，每塊第一行標檔名）。檔案 1「1-說話格式.md」：恆常核心（規則與原句示範成對；六塊：語言表層、推理語氣、頻率上限含口癖觸發條件、場景差分、反例對比三級、去 AI 味守則）＋語境錨點 3 到 6 組（標可修剪）＋開場示範＋尾部重錨卡＋邊界，乾淨無溯源。檔案 2「2-資料庫.md」：口吻手冊逐維（每條「怎麼下筆＋示範字句＋解析＋信心＋（樣本 X）」、多招列成招式庫）、標誌模板庫、節奏與量化錨全表、場景旋鈕詳版、禁用清單三級、刻度卡、原文錨點庫（分組附解析）、僅供理解區（世界觀傾向）。檔案 3「3-來源索引.md」：取樣範圍、樣本索引表（含來源網址與搜尋時間）、維度覆蓋表、驗證紀錄、版本與擴充日誌、擴充指南。
　打包前逐維過維度覆蓋檢核表（表層 12＋深層 11＋口語 6），每一維標「進資料庫／已掃無訊號／樣本不足」寫進檔案 3，不許靜默略過。檔案 1 只放語言表層與推理語氣特徵；世界觀傾向留在檔案 2 僅供理解區，不寫進任何生成指令。
第 6 步：先寫一段不套 profile 的中性版對照（個體化）；再挑一個他沒寫過的主題，照生成 prompt 寫 150 到 250 字，跟真實樣本並排逐條對照，同時查有沒有把特徵放大失真、換題後有沒有抄原內容、讀不讀得通。不像或超標就回去修。

規範：繁體中文、全形標點、禁破折號。不虛構對象的觀點、經歷、立場。抓不到就標樣本不足，不要用印象填補。
```

## 禁止事項

- 不從少量樣本（少於 3 份）推出高信心的完整人格。樣本不夠就標清楚，降信心等級。
- 不虛構對象的政治立場、宗教、私人經歷、未公開資訊。profile 只寫樣本裡有的。
- 不把觀察寫成定性。「樣本裡他常……」可以，「他是個……的人」不行。
- 不用私人對話、私訊、非公開文件當樣本，除非對象明確授權。
- 不協助冒名發布、詐騙、抹黑、假冒背書。涉及冒充真人發言一律拒絕。
- 不把 AI 改寫過的樣本當核心依據，一定降權並標記。
- 沒有搜尋能力時不用記憶裡的印象填補樣本，改成只用提供樣本並下調信心。
- profile 和短 prompt 本身的中文也守去 AI 味規範：全形標點、禁破折號「——」、不用「不僅…更…」「值得注意的是」「總而言之」「讓我們深入探討」，用功能性描述而非抽象人設詞。
- 不把世界觀傾向寫進短 prompt 或檔案 1「說話格式」。它只給人理解對象，壓進生成會把「像他」變成「替他表態」。
- 用仿寫聲音對外產出時，預設標「AI 仿寫、非本人」（可由使用者關閉）。
- 把原文錨點放進要外送的角色卡前，確認授權涵蓋此用途（原文外送，見 `references/authorization-ethics.md` §七）。
- 口語與隨性語體天生較難重現，貼真度上限較低，對口語對象要更多樣本、對「像不像」更保守。
- 不宣稱 profile 100% 準確。它是樣本的歸納，樣本換了結論可能就變。

## 與其他技能搭配

- 跟 `deai-write` 搭：先用本技能抽出 voice profile，把短 prompt（或檔案 1「說話格式」的恆常核心）填進 `deai-write` §0 的「風格輸入」欄，讓它生出來的東西既沒有 AI 味、又帶指定的人的口吻。說話格式已內建對齊 `deai-write` 的去 AI 味守則。
- 跟 `deai-guard` 搭：改寫時如果附上本技能的 profile，可以把「改得更自然」對齊到「改得更像這個人」，而不是改成通用的自然文風。
- 跟 `deai-writing-seo` 搭：要帶特定口吻的 SEO 文，把檔案 1「說話格式」的恆常核心填進它第 3 關的生成輸入，口吻與 SEO 規格並行不衝突。
