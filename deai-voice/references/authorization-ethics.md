# 授權與倫理閘門細則

這是 `deai-voice` 第 1 關的完整版。第 1 關決定樣本怎麼來，過不了就不往下走。SKILL.md 裡是精簡的放行表，這份把灰色地帶、web 搜尋的操作邊界、沒有搜尋能力時的降級路徑、冒名風險自查、拒絕話術都補齊，讓另一個 AI 或人可以逐條照做。

閘門的判斷順序固定：先看對象是誰（本人 / 授權代理 / 具名公眾人物 / 私人），再看樣本來源是不是公開，最後看用途正不正當。三層任一層不過，就停在只用使用者手上已授權的樣本，不主動補樣。任何一步涉及冒充真人發言、詐騙、抹黑，直接拒絕。

## 一、放行表完整版

### 基本情況

| 情況 | 樣本來源 | 是否放行 | 補充 |
|---|---|---|---|
| 對象是使用者本人 | 使用者提供 | 放行 | 最單純，直接進第 2 關 |
| 對象授權使用者代理（有委託關係） | 使用者提供 | 放行 | 請使用者說明授權形式（口頭 / 書面 / 職務關係），存疑就當作沒授權 |
| 具名公眾人物的公開發表內容（文章、書、公開演講、公開貼文） | 使用者提供 或 web 搜尋 | 過倫理檢查後放行 | 只放行「公開發表過」的那部分，見第二節搜尋邊界 |
| 私人對話、私訊、非公開文件 | 任何來源 | 不放行 | 除非對象本人明確授權，且授權涵蓋這批具體內容 |
| 意圖冒充對方發布、詐騙、抹黑、假冒背書 | 任何來源 | 一律不放行 | 用途本身違規，來源再乾淨也不放行，見第四節 |

### 灰色地帶案例

放行表的五種基本情況涵蓋大多數請求。以下三種常見的邊界情況，判斷邏輯拆開講。

**半公開內容（限定範圍可見的貼文、需追蹤才看得到的帳號、封閉社團、付費電子報）**

半公開的意思是內容不對全世界開放，但也不是一對一私訊。判斷標準不是「技術上抓不抓得到」，是「發布者當初預期哪些人會看到」。

- 只有追蹤者看得到的限時動態、鎖粉專用貼文、封閉社團內的發言，預設當私領域，不放行。發布者選擇了範圍，就不是對公眾發表。
- 付費電子報、付費訂閱專欄，內容本身可能是公開發表性質，但取得要付費且常有使用條款限制。不主動搜尋抓取，只有使用者自己是合法訂閱者、自己貼出內容時，才當一般公開樣本處理，並在來源標「使用者提供的付費訂閱內容」。
- 判斷不了是半公開還是全公開，就當半公開，問使用者這批內容當初是對誰發布的。

before（越界）：使用者說「他 IG 限動常講這種話，你上網找找」，就去搜。
after（守線）：回「限動預設是給追蹤者看的私領域內容，我不主動抓。如果你本來就追蹤他、手上有截圖或文字，可以貼給我，我當『使用者提供』處理。」

**已刪除但被存檔的內容（作者刪文、砍帳號，但被網頁存檔站或第三方轉錄留下）**

作者刪除是一個明確的收回動作。存檔站留著不代表作者仍同意被使用。

- 對象已刪除、已刪帳號的內容，即使存檔站找得到，預設不當作可用樣本。刪除意圖優先於可及性。
- 例外：內容在刪除前已被廣泛、正當地引用進其他公開來源（例如刪文前已被新聞報導完整引述），那份「報導裡的引述」可視為公開發表內容，但要標來源是報導轉述，非原文，且註明原文已被作者刪除。
- 使用者若堅持要用存檔原文，說明刪除意圖的問題，把決定權交回使用者，並在 profile 註明「含作者已刪除之存檔內容，授權基礎薄弱」。

**逝者的公開作品**

對象已逝，無法親自授權，處理方式看內容性質。

- 生前正式公開發表的作品（出版的書、公開文章、公開演講逐字稿、公開受訪紀錄），性質上仍是公開發表內容，可比照具名公眾人物的公開內容處理，過倫理檢查後放行。
- 生前的私人書信、日記、未公開手稿，即使因研究或出版而流通，仍帶私領域性質。除非已由著作權繼承人或正式出版程序公開，否則當私人文件，不放行。
- 逝者的內容特別容易被拿去做「假借其名發言」的事。用途檢查要更嚴，任何「以逝者口吻對當代事件發表意見並可能被當真」的用途，一律不放行。

## 二、web 搜尋補樣本的操作邊界

只有通過放行表、對象是具名公眾人物、用途正當時，才進入主動搜尋。搜尋的目的是補「公開發表過的樣本」，不是挖這個人的一切。

### 可以搜什麼

- 公開發表的文章、部落格、專欄（作者具名、公開可讀）。
- 已出版書籍的公開書摘、試閱段落、書店或出版社釋出的節錄。
- 公開演講、公開座談的逐字稿或官方釋出的錄影文字。
- 公開受訪的訪談紀錄（媒體正式刊出的）。
- 對象自己在公開平台、對全體公眾發布的貼文（帳號公開、非鎖定範圍）。

搜到之後每一份都要標來源網址、類型，並在第 2 關按規則分級。

### 不能搜什麼

- 私人社群內容：鎖定帳號、封閉社團、僅追蹤者可見、私訊截圖。
- 洩漏文件：外流的內部信件、被駭或被爆料流出的私人通訊、未經授權外流的草稿。
- 需登入 / 付費才進得去的私域：需要帳號權限、付費牆後、有明確使用條款禁止抓取的內容。
- 拼湊人肉：把散落各處的個人資訊組合起來還原對象私生活，跟提煉語氣無關，一律不做。
- 對象已刪除的內容（見第一節灰色地帶）。

### 搜尋時的自我約束

- 搜的是「這個人怎麼寫、怎麼講」的樣本，不是「這個人的觀點清單」。抓到的內容只用來看語言與推理模式，不拿去當「他主張什麼」的依據。
- 搜到疑似私領域外流的內容，即使公開可及，也不採用，並在紀錄裡說明跳過的原因。
- 一份樣本來源判斷不了是公開發表還是私領域，就不用它，寧缺勿濫。profile 標樣本不足，比混進不該用的內容好。

## 三、沒有搜尋能力時的降級路徑

環境沒有 web 搜尋工具、搜尋被停用、或搜尋通過閘門但實際搜不到足夠內容時，走降級，不硬湊。

降級的四條動作：

1. **只用提供樣本。** 不主動找，範圍收斂到使用者已貼、已授權的那批。
2. **在 profile 開頭註明未補樣。** 明寫「樣本僅來自使用者提供，未做公開內容補樣」，讓讀 profile 的人知道取樣範圍。
3. **下調信心。** 樣本量本來就受限，整體信心等級據此下調。若總數少於 3 份，照第 4 關規則，整份最高只能 medium。
4. **不用印象填補。** 這條最重要。搜不到就是搜不到，絕不拿記憶裡對這個人的印象去補樣本、去猜他會怎麼寫。用印象填補等於虛構，違反誠實邊界。

降級時的自檢問句：

- 我現在寫進 profile 的每一條，是不是都指得回一份實際樣本？
- 有沒有哪一條其實是我對這個人的既有印象，不是從樣本讀出來的？
- profile 開頭有沒有誠實寫出「未補樣、信心下調」？

三條有一條答不出來，回去修，不要輸出。

before（越界）：沒搜尋能力，但「我大概知道這位作家的風格」，於是照印象寫了一份看起來很完整的 profile。
after（守線）：只用使用者貼的 2 份樣本抽取，profile 開頭寫「樣本僅 2 份且未補樣，此為初步觀察，整體信心 medium」，抓不到的維度標 `[樣本不足]`。

## 四、冒名風險自查清單

用途檢查的核心是判斷這份 voice profile 會不會被拿去冒充、詐騙、抹黑。以下問句表，逐題問，任何一題答「是」或「不確定且無法排除」，就停下來，走第五節的拒絕話術。

| 編號 | 自查問句 | 命中處理 |
|---|---|---|
| Q1 | 產出物會不會被拿去假裝是對象本人發布（貼文、留言、聲明、訊息）？ | 命中即拒絕 |
| Q2 | 用途會不會讓第三方誤以為對象真的說了 / 做了某件他沒說 / 沒做的事？ | 命中即拒絕 |
| Q3 | 有沒有金錢、募款、投資、交易的情境，會用到對象的名義或口吻？ | 命中即拒絕（詐騙風險） |
| Q4 | 會不會用來假冒對象背書某產品、某立場、某人？ | 命中即拒絕 |
| Q5 | 會不會用來抹黑對象，或以對象口吻抹黑第三方？ | 命中即拒絕 |
| Q6 | 對象是不是真實可辨識的個人，而產出會流向對象本人以外的受眾？ | 命中則加問 Q7 |
| Q7 | 如果對象本人看到這份產出被這樣用，會不會合理反對？ | 不確定就當作會反對，退回澄清 |
| Q8 | 使用者是否清楚並願意為用途負責？ | 答不清楚就先停，問清楚再說 |

正當用途長這樣（可繼續）：使用者拿 profile 對照自己寫作、團隊統一內部文風、學術或個人研究分析某作者的語言風格、明確標示「AI 仿寫、非本人」的二創或練習。

違規用途長這樣（拒絕）：冒充對象發真實訊息、以對象名義詐財、假冒背書、以對象口吻散布不實內容、騷擾。

判斷灰的時候，用一句話測：「這個用途會不會讓別人把 AI 產出當成對象本人的真實言行？」會，就不做。

## 五、隱私與授權的拒絕話術範本

閘門不過時，不是冷冰冰甩一句「不行」。說明卡在哪一關、為什麼，並盡量給替代方案。以下範本按情況分，照著改成當下的用語即可。

**情況 A：對象是私人 / 內容是私領域**

> 這批內容看起來是私領域的（私訊 / 鎖定範圍 / 非公開文件），我不能拿來做提煉。如果對象是你本人，或對象明確授權你使用這批內容，跟我說一聲我就能繼續。或者，你手上有沒有這個人公開發表過的東西（公開文章、貼文、受訪），那些我可以用。

**情況 B：要主動搜尋，但對象非公眾人物 / 用途存疑**

> 主動上網補樣本，我只對「具名公眾人物的公開內容」做，而且用途要是正當的（自己對照、研究、標明是仿寫的練習這類）。這個對象 / 這個用途我還不能確認符合，所以先不搜。你先貼你手上已經有、且確定可以用的樣本，我用那些做，profile 會註明沒補樣、信心下調。

**情況 C：用途疑似冒名 / 詐騙 / 抹黑（自查表命中）**

> 這個用途我沒辦法協助。做出來的東西會被當成對象本人的真實言行（或被用在冒名 / 詐騙 / 抹黑的情境），這條線我不跨。如果你的實際目的是別的（例如你要標明「這是 AI 仿寫、不是本人」的二創，或你要研究這個人的文風），跟我講清楚用途，我們看能不能換一個不涉及冒充的做法。

**情況 D：灰色地帶內容（半公開 / 已刪除 / 逝者私文）**

> 這批內容處在灰色地帶（半公開範圍 / 作者已刪除 / 逝者的非公開作品），授權基礎不夠穩，我不主動用。如果你能確認它的公開性質，或改用對象正式公開發表的部分，我就能繼續。真的要用，我會在 profile 裡註明授權基礎薄弱，讓你知道這份 profile 的限制。

拒絕時守三點：講清楚卡在哪一關、不指責使用者動機、給一條能往下走的替代路。目的是守住閘門，不是把人推開。
