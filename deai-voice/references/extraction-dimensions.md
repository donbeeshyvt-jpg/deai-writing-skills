# 抽取維度細則

這是 deai-voice 第 3 關（多維抽取）的操作參考。SKILL.md 只列出了維度表格，這份檔把每一維展開成「要問自己什麼、怎麼量化、證據記幾條」，附中文實例對照，並劃出深層維度的越界紅線。

抽取分兩層：表層六維直接數，深層八維要細讀。每個維度都遵守同一個原則，寫下的每一條都要能指回樣本裡的實際文字，指不回去就不寫。

## 通用記法

不管抽哪一維，每條特徵都記三樣東西：

- 這條特徵的一句話描述（描述他怎麼說，不替他定性）
- 證據句：抄樣本原文，不要改寫成你自己的話
- 出現次數與樣本數：寫成「樣本 2、4、5」這種可回查的形式

證據條數的基準（經驗值，非實測，可依樣本量調整）：

- 表層維度：每條記 2 到 3 個證據句就夠，因為表層可量化，數字本身就是證據。
- 深層維度：每條記 2 到 3 段完整證據，深層要看語境，單句抽出來會失真，寧可多抄一點上下文。
- 想標成 high 的特徵：證據要橫跨 3 份以上獨立樣本，證據句就照樣本分開列。

## 一、表層六維逐維操作

### 詞彙

要問自己：他反覆用哪些實詞、有沒有口頭禪、慣用什麼詞開頭、術語密度多高、第一人稱出現得頻不頻繁、有沒有固定的自嘲用語。

怎麼量化：

- 高頻實詞：把樣本斷詞後數名詞動詞的出現次數，挑明顯高於一般用語的。
- 口頭禪與慣用開頭詞：數「欸」「其實」「說真的」「所以說」這類詞出現在句首或段首的次數。
- 術語密度：每百字裡專業術語幾個，用「密／中／疏」三檔質性標，不要硬給小數。
- 第一人稱頻率：數「我」「我們」出現的次數，跟句數相比看比例。

證據要記幾條：每個高頻詞抄 2 到 3 句它出現的原句。口頭禪要記出現次數，因為口頭禪的價值在「他愛用但不濫用」，次數就是後面短 prompt 設上限的依據。

實例對照（同一個意思，兩位作者怎麼寫）：

| | A 作者 | B 作者 |
|---|---|---|
| 要表達「這件事我沒把握」 | 「其實吧，這個我還沒完全搞懂。」 | 「關於這一點，我的判斷仍有保留。」 |
| 差異 | 「其實吧」開頭、口語、直說「搞懂」 | 沒有口頭禪、書面、用「判斷」「保留」這種抽象詞 |

抽取者要記的是：A 靠「其實吧」開頭 加 「搞懂」這種動詞，B 靠「判斷」「保留」這種名詞化用語。這是詞彙層的分野。

### 標點

要問自己：他偏好哪些標點、驚嘆號與問號多不多、有沒有慣用省略號、用不用括號補充、（繁中場景）全形習慣穩不穩。

怎麼量化：

- 驚嘆號問號密度：每千字幾個，用來判斷語氣的外放程度。
- 省略號：數「……」的出現次數，看他是用來留白還是用來拖語氣。
- 括號補充：數（）出現次數，括號多的人傾向邊講邊補充，是一種思路特徵。

證據要記幾條：每種慣用標點抄 2 句原句。標點的證據不用多，重點是點出「他用這個標點在做什麼」。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 同一句補充說明 | 「這方法我試過（大概三次），還是不行。」 | 「這方法我試過，大概三次，還是不行。」 |
| 差異 | 用括號把補充塞進句子，主線不斷 | 用逗號切開，補充跟主線同一層 |

### 句長

要問自己：平均句長多少、句長變化大不大、有沒有慣用極短句作節奏。

怎麼量化：

- 平均句長：以標點斷句，算平均字數。用「短（十字上下）／中（十五到二十五字）／長（三十字以上）」描述即可。
- 變化幅度：看最短句與最長句差多少。差距大的人靠句長對比製造節奏。
- 極短句：數三五字成句的次數，看是不是固定手法。

證據要記幾條：抄一組能看出節奏的連續句子，最好是「長句接一個極短句」這種對比明顯的，一到兩組就夠。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 講一個轉折 | 「我準備了很久，資料查了一整晚，方案改了三版。結果沒人來。」 | 「儘管我做了充分的準備，最終的出席狀況仍不如預期。」 |
| 差異 | 長句鋪陳後接一句極短句收，落差製造情緒 | 一個長句包完，句長平穩，無節奏起伏 |

### 段落

要問自己：平均段長多少、段落是不是等長、換行習慣、有沒有單句成段。

怎麼量化：

- 平均段長：算每段幾行或幾句。
- 等長與否：看段落長度是規律還是忽長忽短。忽長忽短的人常用短段落強調。
- 單句成段：數只有一句話的段落。單句成段是很強的個人手法，一定要記。

證據要記幾條：不用抄整段，記「他的段落結構」這個模式加一個例子位置即可。

實例對照（描述同一段內容的排版差異）：

- A 作者：三四句一段，中間夾一個單句成段當重錘。
- B 作者：每段長度相近，五六句一段，不用單句段。

### 開場

要問自己：文章或段落怎麼起頭。是直接破題、拋問句、講一個場景、還是先給結論。

怎麼量化：不用數字，歸類即可。看多篇樣本的第一句屬於哪種，出現最多的那種就是他的慣用開場。

證據要記幾條：抄 2 到 3 篇樣本的開頭第一句並排放，讓慣用型態自己浮出來。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 一篇談「拖延」的文章開頭 | 「昨天我盯著待辦清單，盯了四十分鐘，一個字沒動。」 | 「拖延的根源在任務設計，不在意志力。」 |
| 型態 | 講場景，用具體畫面切入 | 先給結論，開門見山下判斷 |

### 收尾

要問自己：他怎麼收。回扣開頭、停在事實、拋一個開放問題、還是習慣性升華。

怎麼量化：跟開場一樣歸類。特別注意「習慣性升華」，如果他真的每篇都往上拉一句大道理，照實記，不要因為升華有 AI 味就替他美化或省略。這是他的特徵，不是缺點。

證據要記幾條：抄 2 到 3 篇樣本的最後一句並排。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 同一篇文章結尾 | 「反正下次再說吧，先睡。」 | 「願我們都能與時間溫柔和解。」 |
| 型態 | 停在一個隨性的動作，不升華 | 升華收尾，往上拉一句抽象的話 |

若對象是 B 這種升華型，profile 就照實寫「慣性升華收尾」，短 prompt 也要保留，不然模仿出來就不像他。

## 二、深層八維逐維操作

深層維度要細讀，證據要帶語境。每一維都附「要問自己的問題、怎麼記、實例對照」。

### 推理順序

要問自己：他先給結論還是先鋪背景。偏歸納（從例子推通則）還是偏演繹（從原則推個案）。

怎麼記：引 2 到 3 段能看出他推理骨架的原文，標出結論句在段落的哪個位置（開頭、中間、還是最後）。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 論證「該早睡」 | 「我最近試著十一點睡，白天清楚很多，工作也快。所以早睡真的有差。」 | 「充足睡眠能提升日間認知表現，因此應提早就寢。以我自己為例，改成十一點睡之後確實有感。」 |
| 骨架 | 先講自己的經驗，最後才推出結論（歸納、結論在後） | 先給通則當結論，再補一個例子佐證（演繹、結論在前） |

### 取捨方式

要問自己：面對複雜問題他怎麼取捨、什麼被他放大、什麼被他省略。

怎麼記：記兩件事，他「刻意略過什麼」和「反覆放大什麼」。省略也是特徵，一個從不談細節只談感受的人，跟一個只堆數據不談感受的人，取捨方式南轅北轍。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 講一次專案失敗 | 只講當時的心情跟關係，跳過技術細節 | 只講數據、時程、決策點，不提情緒 |
| 取捨 | 放大人與感受，略過機制 | 放大機制與數字，略過感受 |

### 承認不確定

要問自己：他用什麼句式承認自己不知道、會不會 hedge、hedge 密不密。

怎麼記：抄他承認不確定的原句，例如「我不確定」「應該吧」「這我還沒搞懂」「純屬猜測」。記密度，是每段都 hedge，還是通篇很篤定偶爾才收一句。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 對一個沒把握的判斷 | 「這我不太確定，可能記錯，你再查一下。」 | 「據我所知是這樣。」 |
| 型態 | 明講不確定，還把查證責任交出去 | 用「據我所知」輕輕收一句，語氣仍偏篤定 |

### 對讀者距離

要問自己：他拉近（你我對話）還是保持距離（旁觀陳述）。是教學姿態還是平視。

怎麼記：記人稱用法（有沒有直接喊「你」）和招呼方式。教學型會解釋、會下指令；平視型只陳述自己怎麼看。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 給一個建議 | 「你可以先從最小的一步開始，別逼自己一次到位。」 | 「一個可行的做法是從最小步驟切入。」 |
| 距離 | 直接對「你」說話，像在旁邊帶你，拉近 | 不出現「你」，陳述一個做法，保持距離 |

### 情緒邊界

要問自己：他情緒表達的上限跟下限在哪。會不會激動。激動時怎麼寫。

怎麼記：抄情緒峰值的句子（最激動與最冷靜各一）。看他情緒外放時是靠標點（連續驚嘆號）、靠用詞（罵髒話、用重詞）、還是靠短句連發。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 對一件不公平的事 | 「真的很扯。我不能接受，一點都不能。」 | 「這樣的處理方式，我認為有討論空間。」 |
| 上限 | 情緒直接外放，用重詞加短句疊 | 情緒壓得很低，最激動也只到「有討論空間」 |

### 幽默邊界

要問自己：他有沒有幽默、是哪一種（自嘲、冷面、誇張、諧音）、笑點落在哪。

怎麼記：引一個代表性笑點，拆解它為什麼好笑（是靠反差、靠自貶、還是靠把小事講很大）。沒有幽默也是一個特徵，照實記「樣本中未見明顯幽默」。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 講自己拖稿 | 「我的效率跟便利商店關東煮一樣，看起來很多，其實都在同一鍋泡著。」 | 「我承認進度落後，會盡快補上。」 |
| 幽默 | 誇張加生活類比自嘲，笑點在把拖延講得很具體很蠢 | 無幽默，直述事實 |

### 類比傾向

要問自己：他慣用哪個領域的比喻（工程、運動、料理、生活、自然）。

怎麼記：列 2 到 3 個他實際用過的類比原句，標出比喻的來源領域。一個老用球賽比喻的人跟一個老用煮菜比喻的人，世界觀入口不一樣。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 解釋「先做重要的事」 | 「就像跑馬拉松，前面衝太快後面會垮。」 | 「這就像寫程式，先把核心邏輯跑通，介面再慢慢補。」 |
| 領域 | 慣用運動類比 | 慣用工程類比 |

### 世界觀傾向

要問自己：在這些樣本裡，他反覆從哪個角度看事情。

怎麼記：只記「在樣本裡反覆出現的看事情角度」，一律用「在這些樣本中傾向……」句式。這一維最容易越界，記的是傾向，不是人格結論。

實例對照（正確記法對照越界記法）：

| 可以這樣記 | 不可以這樣記 |
|---|---|
| 「在這些樣本中，他傾向把問題歸到制度設計而非個人努力。」 | 「他是個反雞湯、重結構的人。」 |
| 前者描述樣本裡反覆出現的視角 | 後者替對方的人格下了定性 |

## 三、深層維度越界紅線清單

深層維度最容易從「描述語言」滑進「替對方定性」。守住一條線：描述他怎麼說，不總結他是誰。

分辨方法：能指回具體句式或行為的是描述（可寫）；把人歸成一種性格或身分的是定性（禁寫）。

| 禁寫（替對方定性） | 改成可寫（描述語言與行為） |
|---|---|
| 他很謙虛 | 他常先認錯再解釋（證據：樣本 1、3） |
| 他很自信 | 他下判斷時很少 hedge，多用肯定句收尾 |
| 他是個理性主義者 | 在這些樣本中，他傾向先給數據再談感受 |
| 他很溫柔 | 他給建議時常用「你可以」而非「你應該」 |
| 他脾氣火爆 | 情緒峰值時他用連續短句加重詞，例：「真的很扯。不能接受。」 |
| 他很幽默 | 他慣用生活類比自嘲，笑點多落在把小事誇張化 |
| 他是個悲觀的人 | 在這些樣本中，他談未來時傾向先列風險再談可能 |
| 他很有同理心 | 他描述他人處境時，常先複述對方感受再回應 |
| 他是工程師思維 | 他慣用工程領域的類比解釋抽象概念（證據：樣本 3、5） |
| 他很直白 | 他少用委婉語，結論句多放段首 |

判斷卡住時的自檢問句：這句話換一個人、換一批樣本，還成不成立。如果「他很謙虛」這種話套到別人身上也講得通，那它就沒有指回樣本，是定性，刪掉重寫成可查的描述。

## 四、口語與書面樣本的差異處理

同一個人在不同場景講話不一樣。寫論文跟發限動、做技術文件跟跟朋友聊天，是同一個人的不同面，不能混成一鍋算。

處理原則：樣本類型混雜時，profile 分場景寫。別把技術文件的嚴謹算進他日常的隨性，也別把限動的隨便當成他寫正式東西的水準。

分場景的做法：

- 收樣本時就照 SKILL.md 第 2 關標好類型（長文、貼文、訪談口語、郵件、技術文件）。
- 抽取時把同類型的樣本歸在一起數。口語樣本一組，書面樣本一組。
- 表層維度（句長、標點、詞彙）幾乎一定會因場景不同而不同，要分開記，不要平均。口語句短、口頭禪多、標點隨性；書面句長、術語密、標點規整，這是正常的，不是矛盾。
- 深層維度（推理順序、取捨、對讀者距離）比較可能跨場景一致，如果一致，就是更穩的核心特徵，可以合併記並註明「口語與書面皆然」。如果連深層都因場景而變，那也照實分開記。

實例對照（同一人的兩個場景）：

| | 口語場景（跟朋友的訊息） | 書面場景（部落格文章） |
|---|---|---|
| 句子 | 「欸這個我覺得不行啦，太趕了」 | 「就時程而言，這個安排恐怕過於緊湊。」 |
| 詞彙 | 「欸」「啦」、口頭禪多 | 無語氣詞、用「就……而言」這種書面連接 |
| 深層是否一致 | 兩邊都是先給判斷再講理由（推理順序一致，可合併記） | |

profile 輸出時，若對象樣本跨多場景，在表層特徵下分「口語」「書面」兩區寫；深層特徵若跨場景一致就合併，不一致就同樣分區。

## 五、錯字、口誤、病句的處理

預設不列為特徵。錯字、口誤、漏字、語法錯亂這類東西，多半是當下手誤或輸入法選錯，不是穩定風格。把它們當特徵抽出來，模仿時就會刻意製造錯字，那不是像這個人，是在惡搞。

例外：使用者明確指定「這個錯法就是他的味道」時才收。例如某人固定把某個詞打成某個諧音、固定用一個嚴格說來不合語法但已成個人標記的句式，且這個習慣在多份樣本裡穩定重複。這種情況才收，且一定在 profile 裡標明「刻意保留，經使用者確認為個人標記」。

判斷步驟：

1. 抽取時遇到錯字病句，先不列入。
2. 若某個「錯法」在 3 份以上樣本穩定重複，值得存疑，記到「觀察到但存疑」區，標 low。
3. 主動問使用者：這個寫法是他的固定習慣，還是單純打錯。
4. 使用者確認是刻意標記，才升格為特徵並註明來由；確認是手誤，就從特徵裡拿掉。

一句話原則：手誤不是風格，除非它穩定重複且使用者認證。抽取者沒被授權自己認定某個錯字是特徵。

## Codex 版補充（保留 voice-style-distill 的獨有維度與門檻）

以下三項來自前身技能 voice-style-distill 的 SKILL.md，base 尚未涵蓋其實質內容，補進來只增不減。

### 補充一、視角維度：我／你／我們的比例與使用場景

base 的「詞彙」維度有數第一人稱頻率，「對讀者距離」有記「你」的用法，但沒有把「我／你／我們」當成一個獨立的量化比例維度來抽。這一維專門補這塊。

要問自己：三個人稱各占多少、哪個場景切到哪個人稱。

怎麼量化：

- 分別數「我」「你（你們）」「我們」的出現次數，算三者的相對比例（用「以我為主／以你為主／我們並列」這種質性描述即可，不必硬給百分比）。
- 記每個人稱的使用場景：講經驗時用「我」、給建議時切到「你」、談共同處境時用「我們」。人稱的切換點本身就是特徵。

證據要記幾條：每個人稱抄 1 到 2 句代表性原句，並標出它出現在什麼場景（敘事、建議、拉近）。

實例對照：

| | A 作者 | B 作者 |
|---|---|---|
| 講一個共同煩惱 | 「我們是不是都有過那種，話到嘴邊又吞回去的時候？」 | 「多數人都經歷過欲言又止的情況。」 |
| 視角 | 用「我們」把讀者拉進同一條船，我你界線模糊 | 用「多數人」旁觀陳述，不出現人稱，保持距離 |

抽取者要記：A 靠「我們」建立共感、把讀者納入；B 幾乎不用人稱、用「多數人」這種泛稱維持旁觀。這是視角層的分野，跟「對讀者距離」互補：距離維度看拉近或疏遠，視角維度看用哪個人稱去拉近。

### 補充二、樣本需求的具體門檻（最低與理想）

base SKILL.md 第 2 關寫「目標 5 份以上、每份 300 字以上」，但沒有給「1 篇長文即可」的替代門檻，也沒有把最低與理想分層列清。補上明確門檻：

最低可用（達到才開始抽，否則只能出 provisional profile 並列缺口）：

- 3 段以上同一人的文字，每段 300 字以上。
- 或 1 篇 1200 字以上長文（單篇夠長時，可暫代多段的最低量，但單篇無法檢查跨場景穩定性，整體信心仍受限）。

理想（達到才可能標到 high）：

- 5 到 10 篇不同情境樣本。
- 標註發表場景：blog／social／chat／email／script／doc。
- 同時包含好樣本與「不要模仿」的壞樣本。
- 有使用者說明：哪些地方像自己、哪些不想保留。

這組門檻跟 base 第 4 關的樣本量降級表相容：3 到 4 份對應整體信心上限 medium，5 份以上才解除壓制。單篇 1200 字這條是 base 原本缺的替代路徑，補進來讓「只有一篇長文」也有明確依據可走。

### 補充三、提煉提醒：主題強相關詞不要當通用語氣

base 已充分講「重複才進核心」「AI 改過的樣本降權」，但沒有明講一條容易踩的坑：與內容主題強相關的詞，不要當成通用語氣抽出來。

- 只把重複出現的模式列為核心；單次出現的有趣句子列為「可選特色」，不進核心（base 把單次出現放存疑區，這裡補上「可選特色」這個定位，供短 prompt 斟酌少量使用）。
- 與內容主題強相關的詞不要當成通用語氣。舉例：某人這批樣本都在談登山，「稜線」「重裝」「撤退」這些詞高頻出現，那是題目帶來的，不是他的語氣特徵。換個題目這些詞就消失了。抽取時要把「因為在講這件事才出現的詞」跟「不管講什麼都會冒出來的慣用詞」分開，只有後者才是通用語氣。
- 分辨方法：設想他換一個完全無關的題目寫，這個詞還會不會出現。會，才是語氣詞；不會，是主題詞，別當通用特徵。
