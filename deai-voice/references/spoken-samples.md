# 口語樣本的逐字處理與口語專有維度

這是 deai-voice 抽取層的口語補充。當樣本來源是語音（訪談、播客、語音訊息、直播、對談逐字稿）時，先套這一層，再回到 `extraction-dimensions.md` 抽共通維度。

為什麼要獨立一層：`extraction-dimensions.md` §四把樣本分口語與書面兩區，但它假設輸入已經是乾淨文字。語音源不是。停頓、重疊、改口、拉長音、未完成句，這些最能認人的訊號，在「把逐字稿清成通順文字」那一步就被抹掉了。清乾淨之後再抽，抽到的是一個被書面化過的假口吻。所以口語樣本的第一步不是抽取，是「別急著清乾淨」。

這一層只在樣本確實來自語音時啟用。純書面對象不要套，否則 profile 會膨脹出一堆用不上的口語欄位。

## 一、第一步：逐字，別清乾淨

拿到語音樣本，先取逐字記錄，保留下面這些，別在抽取前就順稿：

- 停頓（短停、長停）與它落在哪裡
- 重疊與插話（兩人同時講、被打斷）
- 拉長音（「這個⋯⋯」的延長）
- 重講與改口（話講到一半重來）
- 明顯的語速變化（哪裡快、哪裡慢下來）
- 填充詞與語尾助詞，原樣保留，不刪

會話分析有一套通用的逐字記法（Jefferson 式），用符號標停頓長度、重疊起訖、拉長音、升降調。這裡不要求照搬整套，只借它的精神：**先把口語的顆粒完整記下來，抽完特徵之後再決定要不要清稿。** 需要用到記法時，在 profile 註明用了哪種記法即可，別讓符號嚇到讀 profile 的人。

一句話原則：書面樣本抽「寫出來的字」，口語樣本抽「怎麼講出來的」，後者包含大量不在字面上的東西，清稿等於先刪掉一半證據。

## 二、口語專有維度

下面六維是書面抽取表沒有、或只輕輕帶過的。每一維沿用父技能通用記法：一句話描述、證據句（抄逐字原文，含停頓改口）、出現次數與樣本數。

### 填充詞

書面的「口頭禪」在口語裡要拆得更細。填充詞不只看用哪幾個，更要看**位置**，位置本身是指紋。

要問自己：他偏好哪幾個填充詞（那個、這個、就是、呃、欸、嗯）、多密、通常出現在哪個位置。

怎麼記：

- 偏好：數哪幾個明顯偏多。
- 密度：用疏／中／密三檔質性標，不硬給每分鐘幾個。
- 位置：這是重點。填充詞出現在難詞前（在找詞）、搶話時（先佔住發言權）、還是換題時（過場），三種位置是三種不同的說話反射。

實例對照（虛構）：

| | 甲 | 乙 |
|---|---|---|
| 找不到詞時 | 「那個⋯⋯就是那種，你知道的那種感覺」 | 直接停頓兩秒，不填詞，想到才講 |
| 差異 | 用「那個」「就是」填住空檔，不讓對話斷 | 容許沉默，寧可停也不填 |

甲乙的填充策略南轅北轍，這比「兩人都愛用那個」有用得多。

### 自我修正

講到一半改口，是口語最個人化的特徵之一。注意：這**不是**錯字口誤，不要被 `extraction-dimensions.md` §五「錯字口誤預設不算特徵」誤刪。錯字是手誤，自我修正是一種穩定的說話方式，要收。

要問自己：他中途改口時，是硬切換一個講法、整句重講、還是插一句「我是說」「就是說」再修。

怎麼記：抄 2 到 3 段有改口的原文，標出他修正的方式。

實例對照（虛構）：

| | 甲 | 乙 |
|---|---|---|
| 講錯要修 | 「這個要三天，喔不是，是三週」 | 「這個要三天。我是說，扣掉等料的時間三天，全部算下來是三週」 |
| 修正方式 | 硬切，「喔不是」一句話換過去 | 插「我是說」再補一整段解釋，把修正過程也講出來 |

劃界提醒：自我修正記的是「怎麼修」這個穩定手法，不是記他某次講錯的那個具體錯誤。同一種修正方式要跨樣本重複才進核心。

### 未完成句與容許不完整

口語充滿沒講完的句子、開了頭又換方向（false start）、重複同一個詞卡住。書面抽取會把這些當雜訊補成完整句，但對口語對象，**未完成本身是特徵**。一個習慣把句子講完的人，跟一個常常話說一半靠語氣收掉的人，聽起來完全不同。

要問自己：他句子的完成度多高、常不常話講一半、靠什麼把沒講完的句子收掉（語氣、停頓、對方接話）。

怎麼記：抄幾句他典型的未完成句，別補全。標它怎麼收（自己停掉、被對方接走、拉長音帶過）。

短 prompt 對應：口語向的短 prompt 要加一個「容許不完整句」的旋鈕，讓下游 AI 知道不用每句都寫工整。書面向的短 prompt 不加這條。

### 句末語氣詞（中文口語最容易一眼認人）

書面抽取的「標點」維度管不到語氣詞，但中文口語裡「吧、呢、嘛、啦、啊、喔」是最快能認出一個人的訊號。這一維把它升成獨立維度，並記每個語氣詞在做什麼功能。

跟 `extraction-dimensions.md` 的虛詞子項分工：那邊抽「偏好哪些語氣詞」這個通用傾向；這裡對口語樣本做**功能對照**，記每個語氣詞承擔什麼語氣任務。兩處不重複記同一件事。

功能對照表（通用，非某人專屬）：

| 語氣詞 | 常見功能 | 口語例（虛構） |
|---|---|---|
| 吧 | 軟化、留餘地、徵求同意 | 「應該可以吧」 |
| 嘛 | 講道理、帶點理所當然 | 「本來就是這樣嘛」 |
| 啦 | 收尾、不耐、把話講定 | 「好了啦，就這樣」 |
| 呢 | 拋問、停頓思考 | 「那這個呢」 |
| 啊 | 強調、情緒外放 | 「對啊，就是這個」 |
| 喔 | 提醒、恍然、輕微驚訝 | 「原來是這樣喔」 |

抽取時記各自密度、慣用來做哪種功能；偏好哪幾個沿用虛詞維度所抽，此處不重列。有人靠「吧」全程軟化，有人靠「啦」把每句話講死，這是很強的個人標記。

### 互動維度（僅對話型樣本啟用）

獨白型樣本（一個人講的演講、口播）沒有這一維。只有雙人或多人對話的樣本才抽。

要問自己：他會不會打斷、搶話、讓話；附和密不密；留不留長停頓。

怎麼記：

- 話輪：他傾向搶話（對方沒講完就接）、等對方講完才接、還是常把話讓給對方。
- 附和：附和詞（嗯、對對對、真假、然後呢）多不多，是邊聽邊回還是聽完才回。
- 停頓容忍：對話裡出現沉默時，他急著填還是能放著。

實例對照（虛構）：

| | 甲 | 乙 |
|---|---|---|
| 對方講到一半 | 「對對對我懂，然後那個⋯⋯」（接話搶拍） | 安靜聽完，停一下才回「嗯，我的看法是」 |
| 互動風格 | 高附和、愛接話、怕冷場 | 低附和、等輪次、容忍沉默 |

### 語速與節奏

書面的「句長」抽字數，口語還要抽語速與它的變化。

要問自己：他整體語速快慢、哪裡會突然慢下來或加速。

怎麼記：用快／中／慢描述整體，並記「他在什麼時候變速」（講重點時放慢、講熟悉的東西時飆快、緊張時加速）。變速的觸發點比平均語速更能認人。逐字稿看不出絕對語速時，靠停頓密度與斷句長度間接估，並註明是估的。

## 三、口語特徵的密度是旋鈕，不是定值

填充詞、語氣詞、改口的密度，受當下狀態影響很大。同一個人緊張時填充詞飆高、放鬆時幾乎不填；累的時候改口變多。所以：

- 密度在 profile 裡標成低／中／高的**旋鈕**，不寫死一個數字。
- 一個口語習慣要**橫跨不同狀態的樣本**重複，才編碼進核心。只在一份（可能剛好很緊張那次）樣本裡爆量的填充詞，標 low，放存疑區。
- 這條與 `confidence-and-stability.md` 的「口語特徵狀態依賴」呼應，信心分級時一併看。

## 四、口語向短 prompt 的額外旋鈕

口語對象打包成資料包（見 `voice-pack-format.md`）時，§2 生成 prompt 除了通用規則，補這幾個口語專屬旋鈕：

- 填充密度：低／中／高（照 profile 抽到的實際密度）。
- 容許不完整句：開／關。開的話允許話講一半靠語氣收。
- 句末語氣詞：列偏好的那幾個與各自功能，附一句「別每句都掛」。
- 互動風格（對話場景）：搶話／等輪／讓話；附和密度。

提醒一句貼真度上限：口語與隨性語體天生比結構化書面語難重現，下游 AI 模仿 casual voice 的貼真度上限較低。所以口語對象要求更多樣本、跨更多狀態，且對「像不像」的宣稱更保守。這條寫進 `confidence-and-stability.md`，這裡呼應。

## 五、與書面抽取的分工總表

| 事項 | 書面樣本 | 口語樣本 |
|---|---|---|
| 第一步 | 直接抽 | 先逐字，別清乾淨（本檔第一節） |
| 口頭禪 | 抽慣用開頭詞 | 拆成填充詞，看位置（本檔二） |
| 改口 | 多半是錯字，不收 | 自我修正，是特徵，要收（本檔二） |
| 未完成句 | 補全或當雜訊 | 是特徵，別補全（本檔二） |
| 語氣詞 | 標點維度帶不到 | 獨立維度加功能對照（本檔二） |
| 互動 | 無 | 話輪、附和、停頓容忍（本檔二） |
| 密度 | 相對穩定 | 旋鈕，受狀態影響，跨狀態重複才編碼（本檔三） |

同一個人若同時有口語與書面樣本，照 `extraction-dimensions.md` §四分場景寫，別把口語的填充密度算進他寫作的風格，也別把書面的工整算成他講話的樣子。
