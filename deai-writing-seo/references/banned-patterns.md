# 禁用句型速查（本技能自帶版）

這是 deai-writing-seo 第 3 關（新寫）與第 5 關（去 AI 味）用的禁用清單。本技能自帶這份，不依賴其他技能；環境裡也裝了 `deai-write` 的話，它的 `references/banned-patterns.md` 有逐類的 before／after 範例，可以拿來對照。

## 一、先讀：聚集才算數

單一特徵不算證據，多個特徵在同一段疊在一起才是 AI 味。所以清單分三層，處理力度不同：

| 層級 | 怎麼判 | 動作 |
|---|---|---|
| 永遠不寫 | 出現一次就算 | 見到就換 |
| 聚集才算 | 同段或鄰段疊了好幾個 | 抓到一叢才拆，抓到一個不動手 |
| 密度過高 | 看全篇比例 | 只在總掃時調 |

## 二、永遠不寫

- 不僅⋯更是⋯（所有「不僅 A，更 B」的變體）
- 不是 A 而是 B（用來假裝有深度的轉折）
- 值得注意的是、不難發現、顯而易見（過場提示）
- 在當今⋯時代、隨著⋯的發展（宏大開場）
- 破折號 `——`

## 三、聚集才算：常見 AI 句型與替代寫法

| 類別 | 禁用 | 改成 |
|---|---|---|
| 工整對稱 | 透過 A 達成 B（加上第二節那兩種對稱句） | 直接講結論，刪掉前半句的鋪墊 |
| 假深度 | 這不只是 A，更是 B | 直接講那件事 |
| 升華總結 | 這讓我想起、其實這就是、歸根結底 | 停在具體事實 |
| 空泛重要性 | 至關重要、不可或缺、意義重大 | 講不做的具體後果 |
| 模糊權威 | 專家指出、研究顯示、業界普遍認為（沒有來源） | 具名來源加年份，查不到標 `[待查]` |
| 翻譯腔 | 透過⋯來實現、對於⋯而言 | 拆成主語加動詞的直述句 |
| 假口語 | 真的太香、直接封神、寶藏（沒有場景） | 給具體場景細節 |
| 過場套話 | 接下來讓我們、首先其次最後的空殼三段 | 刪掉，直接講內容 |
| 金句收尾 | 段末掛「⋯展現了⋯」「⋯反映出⋯」 | 刪掉尾巴，停在事實 |
| 假代理 | 數據告訴我們、時代呼喚著 | 把真正做判斷的人擺回主語 |

排比、轉折詞（但／然而／其實）、用「說到底」「真正的」起頭，單獨出現是正常中文；同段疊三個以上才處理。

## 四、密度過高才調

- 轉折詞整篇明顯比一般人說話密。
- 粗體全篇超過 3 到 4 處，或每節都掛一顆粗體金句。
- 連續三段以上長度幾乎一樣，像被切齊。

## 五、標點硬規則

- 中文正文一律全形：，。：；！？（）「」。半形標點不混進中文句子。
- 破折號的替代：表停頓用逗號；補充說明用括號；要引出一整句就另起一句。
- 中文與英文、中文與數字之間留一個半形空格；緊貼全形標點時不加。

## 六、不是 AI 味的情況（誤判放行）

- SEO 標題、H2、前 100 字重複核心關鍵字：這是刻意的結構，不要拿同義詞輪流換掉。
- 技術文件的穩定術語：同一個概念從頭到尾用同一個詞才是對的。
- 非母語寫手的「透過⋯實現」：可能只是他的用詞習慣，重點放內容密度與邏輯。
- 500 字以下的短文：短、密、沒有鋪陳，是它本來的樣子。
- 真的有三項並列時的三連句：三個步驟、三個原因寫成三段是對的。

判準一句話：先確認它是不是那個場景本來就該有的樣子，再決定動不動手。
