# 修飾詞功能判斷與具體化細則

這是 deai-writing-seo 第 4 關的展開版，也是「去複詞不失真」的核心。這套規則的立場一句話：**該限制的是修飾詞的「功能」，不是「詞性」。** 全面禁止形容詞與副詞是錯的，會產生三種反效果（見第四節防呆）；逐詞判斷功能才是對的。

## 一、為什麼抽象修飾詞是 AI 味的主源

AI 文字常用抽象修飾詞代替真正的資訊：重要、有效、深入、全面、明確、顯著、專業、優質、高度、適當。問題不在這些詞的詞性，在它們**只表達了作者的評價，沒有交代評價依據**。

限制這類詞，會迫使文字回答：誰做了什麼、影響哪個對象、發生什麼變化、根據什麼判斷、在什麼條件下成立、有哪些可觀察結果。這才是空泛感消失的原因。

## 二、功能判斷表

逐詞過，按功能決定去留：

| 修飾詞的功能 | 處理 |
|---|---|
| 只放大語氣（非常、極度、超級，後面沒有依據） | 刪除 |
| 只宣告品質或價值（優質、卓越、出色） | 改成判斷依據 |
| 重複動詞或名詞已有的意思（成功地完成、徹底地毀滅） | 刪除 |
| 只是讓文字顯得正式（相關、進行、予以） | 刪除 |
| 表達時間、範圍、否定、頻率（已經、僅、尚未、通常） | 保留 |
| 控制結論確定程度（可能、大致、不一定） | 保留 |
| 區分技術規格或條件（相容於、限用於、預設） | 保留 |
| 提供可觀察、可辨識的特徵（防水的、半形的） | 保留 |
| 代替證據與具體描述（效果顯著 → 該講數據） | 改寫 |
| 能壓縮原本更冗長的說明 | 保留 |

## 三、四問測試

不要問「這是不是形容詞或副詞」，改問四個問題：

1. **刪除後，原意是否改變？** 不改變就傾向刪。
2. **這個詞是否提供可辨識的差異？** 沒有差異、只是加強語氣，就傾向刪。
3. **這個詞能否被事實、條件或觀察結果取代？** 能取代就改成更具體的內容。
4. **這個詞是否在控制結論的範圍與可信度？** 是就必須保留。

第 4 問是安全網：「可能」「通常」「僅」「尚未」「不一定」這類詞刪掉後，推測會變斷言、局部結論會變普遍結論。這不是文風問題，是準確性問題，永遠優先於簡潔。

## 四、防呆三條（機械式刪詞的反效果）

1. **嬰兒句**：把所有句子切短，變成「系統啟動。使用者登入。資料傳送。」句子短不等於自然，也不等於資訊密度高。句子長度由內容決定：短句放判斷、轉折、重點；長句交代關係、條件與因果。長短自然交錯，別連續同構同長。

2. **名詞化轉移**：禁了形容詞後，模型把抽象內容換成名詞化表達：執行優化、進行改善、完成強化、實現提升。贅詞只是換了件衣服，病還在。抓法：看到「動詞＋抽象名詞」的空泛組合，問它具體改了什麼、變化多少。

3. **假具體**：資料不足時編數字、編品牌、編時間、編感官細節來製造具體感。這比空話更糟，是造假。資料不足就標 `[待補]` 或保留不確定性，只有來源素材中存在、使用者提供、或能可靠查證的細節才可使用。

## 五、有意識的省略（節制原則）

精簡的正確做法是有意識的省略，不是機械刪詞。省略前必須確認四件事：

1. 作者自己已理解被省略的資訊（不懂而省略只會留下空洞）。
2. 讀者能從上下文、行動、對話、事實或前後關係中推斷回來。
3. 省略不會破壞因果、條件、定義與結論。
4. 省略後文字更集中，不是變得更空。

配套原則：

- 能透過行動、選擇、後果、細節、對比呈現的情緒與價值，不額外替讀者解釋（少直接命名情緒，讓細節自己講）。
- 但分析、教學、技術與決策內容不得為了含蓄而藏結論：該說的限制、風險、判斷，直接說。
- 每個留下來的修飾語都必須至少完成一項功能：改變語意、限制範圍、提高精確度、建立必要對比、壓縮說明、或提供可辨識特徵。一項都沒有就刪。

## 六、具體化原則

當內容做出評價或宣稱時，優先補上：

- 判斷依據（根據什麼說它好）
- 發生條件（什麼情況下成立）
- 運作機制（為什麼會這樣）
- 可觀察差異（讀者能自己驗證什麼）
- 實際限制（什麼時候不適用）
- 對讀者的直接影響（干他什麼事）

優先使用有明確主體、動作與對象的句子：名詞指具體事物，動詞承擔主要動作，減少名詞化、被動化與空泛動作。

再劃一次紅線：具體化不等於強迫加入數字、品牌、時間、感官細節。編出來的具體是造假，標 `[待補]` 是誠實。

## 七、人味真實性規則

人味來自作者真正擁有的觀察、經驗、偏好、限制、判斷與語氣，不是人工植入瑕疵。

只有使用者提供相關素材時，才可保留或整理：親身經歷、使用過程、猶豫與取捨、判斷錯誤、工作限制、不適用情況、對特定細節的個人反應。

四不：

- 不強迫每篇加入尷尬、失敗、笨拙、自嘲或反差幽默。
- 不硬造金句（不在段末刻意製造「值得收藏」的句子）。
- 不表演口語（不機械式塞「其實」「就是」）。
- 不表演不確定（只有真實未決才寫不確定）。

幽默與創意只在使用者要求時加入，來源是觀察角度、邏輯落差、語氣與內容的反差，不是固定笑點公式。未要求時，以清楚、精確、自然為主。

## 八、產出後逐句自檢清單

過完第 4 關，逐句確認：

- 是否存在只放大語氣而不增加資訊的詞。
- 是否用抽象評價代替判斷依據。
- 是否有修飾詞重複名詞動詞已有的含義。
- 是否把必要的不確定性與適用範圍刪掉了。
- 是否只是把抽象內容轉移成名詞化表達。
- 是否能以更明確的主體、動作、對象或結果表達。
- 是否省略了讀者理解所需的關鍵前提。
- 是否出現大量過短、破碎或節奏相同的句子。
- 是否仍保留作者原本的語氣、立場與資訊精度。
- 是否每句都提供新資訊、必要限制或推進作用。
